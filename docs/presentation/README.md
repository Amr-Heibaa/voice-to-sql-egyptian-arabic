## 3. How the deck is produced

1. **Master deck** lives in the University Drive (`04-Presentation`), not in this repository. George sets up the master early so owners draft directly in it.
2. Each owner drafts their slides **after** the matching document section has real content, and writes **English speaker notes** for each slide.
3. Slide 13 must use the P2 and P4 definitions exactly as written in [../SPECIFICATION.md](../SPECIFICATION.md) §15.1, labelled as planned evaluation. No numbers that look like results.
4. George integrates the deck (`CQP-20`) and checks titles, order, terminology, figure consistency and that the slide count is exactly 15.
5. Abdallah (`CQP-21`) runs the Q&A bank and readiness checklist, including the formal-attire confirmation.
6. **9 Nov rehearsal:** full English run-through with timing, live demo on the presentation laptop, venue network check and the contingency plan.
